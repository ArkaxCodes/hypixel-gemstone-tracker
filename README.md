# Hypixel Gemstone Price Tracker

Live tracking tool for Hypixel Skyblock gemstone prices. Find the most profitable gems to mine and craft.

## Features
- Live prices from the official Hypixel Bazaar API (no API key needed), auto-refreshing every minute
- All 12 gemstones (Crystal Hollows + Glacite Tunnels), Rough through Perfect
- Insta-buy / insta-sell prices, spread and weekly volume
- Crafting calculator for every upgrade (80 → 1, Perfect: 5 Flawless → 1) with buy-order/insta-buy and sell-offer/insta-sell modes and adjustable bazaar tax
- Search, location and tier filters, sorting; settings are remembered
- Mobile-responsive design

## Files
- `index.html` – page markup
- `style.css` – styles
- `script.js` – data fetching, price parsing and rendering
